# The sample's shape, written the way code is written: outside in, outermost level first, one line per level.
# The proof (checks/rewind.py) reads it inside out, the way a recursion rewinds. Line order is never used.
#   level | script(s) | gets "<file>" from <level below>   (or: from outside: <what>)
# optional parts:  | repeats over "<file>"   | delivers
deliver | deliver.py | gets "batch.json" from build | delivers
build   | build.py   | gets "due.json" from outer
outer   | outer.py   | gets "read_log.jsonl" from read | repeats over "pull.json"
read    | read.py    | gets "saved" from save
save    | save.py    | gets "pull.json" from fetch
fetch   | fetch.py   | from outside: source
